# 競艇バックテストLAB Discord参加・投稿規約（草案）

制定日: [要入力]

最終改定日: [要入力]

## 第1条（目的）

1. 本コミュニティは、過去のボートレースデータに関する仮説、検証条件、バックテスト結果及び学びを、会員同士が安全かつ建設的に共有することを目的とします。
2. 本コミュニティは、舟券の販売若しくは購入の受付・代行、賭けの募集又は有料予想の売買を目的としません。
3. 本コミュニティで共有される情報は、将来のレース結果、的中又は利益を保証しません。

## 第2条（適用関係）

1. 参加者は、本規約、アプリ利用規約、プライバシーポリシー、Discordの利用規約及びコミュニティガイドラインに従います。
2. 本規約とDiscordの規約が抵触する場合、Discord上の利用についてはDiscordの規約が優先します。

## 第3条（参加資格）

1. 参加者は、20歳以上で、当方が指定するベータ会員、有料会員又は招待対象者に限ります。
2. 参加資格は本人にのみ付与されます。
3. 会員資格の終了、利用停止又は退会に伴い、コミュニティの参加資格も終了又は停止する場合があります。

## 第4条（Discordアカウント及び招待の管理）

1. 参加者は、本人が管理するDiscordアカウントを使用します。
2. Discordアカウント、招待URL、ロール又は閲覧権限を第三者へ貸与、共有、譲渡、販売又は公開してはなりません。
3. 招待URLの漏えい又は不正利用を知った場合、直ちに運営へ報告してください。
4. 運営は、会員状態の確認、招待の失効及びロールの変更を行うことができます。

## 第5条（表示名及びプロフィール）

1. 他人又は運営になりすます表示名、誤認を招く肩書き、差別的又は不快な名称を使用してはなりません。
2. 本名、住所、電話番号、投票口座情報その他不要な個人情報をプロフィールへ掲載しないでください。

## 第6条（検証投稿の基本形式）

検証結果を投稿するときは、可能な範囲で次を記載してください。

1. 仮説
2. 対象期間
3. 対象条件及び除外条件
4. 対象レース数又はサンプル数
5. 検証結果
6. 通常条件又は比較対象との差
7. 回収率を表示する場合は、買い目、購入単位及び計算方法
8. 限界、注意点又は次に検証したいこと

## 第7条（正確性と再現性）

1. 数値、対象期間、条件又は出典を意図的に改変してはなりません。
2. 都合のよい期間又は結果だけを切り取り、一般的に再現するかのように表示してはなりません。
3. 投稿後に誤りを発見した場合、速やかに訂正又は削除し、訂正箇所が分かるようにしてください。
4. 他の参加者から合理的な確認を求められた場合、可能な範囲で条件又は計算方法を説明してください。

## 第8条（禁止表現）

1. 「絶対」「確実」「鉄板」「必勝」「必ず勝てる」「利益保証」その他、的中又は利益が保証されると誤認させる表現を禁止します。
2. 過度に射幸心をあおる表現、借入れ又は生活資金での購入を促す表現を禁止します。
3. 過去の結果を将来の確定的な結果として表現してはなりません。

## 第9条（売買、勧誘及び金銭行為の禁止）

次の行為を禁止します。

1. 有料予想、情報商材、必勝法、ツール又は会員権の販売
2. 舟券購入の受付、代行、共同購入、代理購入又は名義貸し
3. 賭け、賞金、参加料その他現実の価値を伴う偶然性の高いゲームの募集又は運営
4. 金銭、暗号資産、ポイントその他価値の貸借又は送金依頼
5. アフィリエイト、紹介報酬、外部サービス又は別コミュニティへの無断勧誘
6. 無断DMによる営業、勧誘又は継続的な連絡

## 第10条（外部転載及び共有）

1. 他の参加者の投稿、会話、プロフィール、画像、検証条件又は個人情報を、本人及び運営の許可なく外部へ転載してはなりません。
2. 運営が発行する外部共有用カード又は共有URLは、表示を改変せず、個人的かつ非商業的な範囲で共有できます。
3. 共有カードに含まれるサービス名、出典、注意書き又はリンクを削除若しくは隠してはなりません。
4. コミュニティ内のスクリーンショットを外部共有する場合、写り込むすべての参加者及び運営の事前承諾を得てください。
5. 営利目的の転載、広告利用又は記事掲載は、運営の事前承諾を必要とします。

## 第11条（スクレイピング及び自動化の禁止）

1. Bot、セルフBot、クローラ、スクレイパー、スクリプトその他の自動化手段を、運営及びDiscordの事前承諾なく使用してはなりません。
2. 投稿、添付ファイル、参加者一覧、メッセージ履歴又は検証結果を継続的若しくは大量に取得、保存又はデータベース化してはなりません。
3. 取得情報を販売、再配布、競合サービス、データセット又はAIモデルの学習・評価に利用してはなりません。
4. 運営が承認したBotは、承認された目的、チャンネル、権限及び保存期間の範囲でのみ利用できます。

## 第12条（個人情報及びセキュリティ）

1. 本名、住所、電話番号、メールアドレス、本人確認書類、カード情報、投票口座情報、ログイン情報、Cookie又は認証コードを投稿してはなりません。
2. 他人の個人情報を本人の同意なく投稿してはなりません。
3. 不審なURL、添付ファイル、アプリ又はDMを受け取った場合、開かずに運営へ報告してください。
4. アカウント乗っ取り又は情報漏えいを知った場合、直ちにDiscord及び運営へ連絡してください。

## 第13条（知的財産権）

1. 投稿者は、投稿に必要な権利を有する内容のみ投稿できます。
2. BOAT RACE公式サイト、報道、SNS、書籍、動画その他第三者の文章、画像、表、映像又はデータを、権利者の許可なく大量転載してはなりません。
3. 引用する場合は、法令上認められる範囲で、引用部分を明確に区別し、出典を表示してください。
4. 権利侵害の申告があった投稿は、確認中に一時非表示又は削除する場合があります。

## 第14条（AI生成コンテンツ）

1. AIで生成又は大幅に加工した文章、画像、音声又は動画を投稿する場合、必要に応じてAI生成であることを表示してください。
2. AIが生成した数値、出典又はレース結果を確認せず、事実として投稿してはなりません。
3. 実在人物のなりすまし、無断の顔・声の模倣又は誤解を招く合成コンテンツを禁止します。

## 第15条（コミュニケーション）

1. 意見ではなく、条件、数値及び根拠を中心に議論してください。
2. 誹謗中傷、脅迫、差別、性的嫌がらせ、執拗な批判、荒らし又は晒し行為を禁止します。
3. 検証の失敗、外れ又は異なる意見を理由に、参加者を攻撃してはなりません。
4. チャンネルの目的と無関係な連投、宣伝、チェーンメッセージ又はスパムを禁止します。

## 第16条（運営及びモデレーション）

1. 運営は、規約違反、安全上の懸念又はチャンネル運営上の必要がある投稿を、事前通知なく削除又は移動できます。
2. 運営は、違反の内容、故意性、反復性及び影響に応じ、注意、警告、投稿制限、タイムアウト、ロール変更、一時停止又は退会措置を行います。
3. 重大な不正アクセス、詐欺、脅迫、個人情報漏えい、違法行為又は反復違反については、警告なしに停止又は退会とする場合があります。
4. 運営は、必要に応じてDiscord、関係事業者又は公的機関へ報告できます。

## 第17条（通報及び異議申立て）

1. 規約違反又は安全上の問題は、[通報チャンネル又は問い合わせ先を要入力]へ報告してください。
2. 公開チャンネルで違反者を晒し、集団で攻撃し、又は独自に制裁してはなりません。
3. 措置に異議がある場合、[問い合わせ先]へ理由及び関連情報を添えて申し立てることができます。

## 第18条（投稿の権利と運営利用）

1. 投稿内容の権利は投稿者又は正当な権利者に留保されます。
2. 投稿者は、運営に対し、コミュニティの提供、保存、表示、バックアップ、検索、モデレーション及び不正防止に必要な範囲で投稿を利用することを許諾します。
3. 運営が投稿を広告、SNS、note、YouTube又は事例紹介へ転載する場合、投稿者の個別同意を得ます。ただし、本人を識別できない統計又は運営発行の共有カードを除きます。

## 第19条（退出及び投稿の取扱い）

1. 参加者はいつでもDiscordサーバーから退出できます。ただし、有料プランの解約は別途アプリ又はStripeで行う必要があります。
2. 退出後の投稿について、参加者は運営へ削除を申請できます。
3. 会話の連続性、他者の権利、規約違反記録又は法令上の必要により、匿名化して保存する場合があります。
4. 削除方針及び保存期間はプライバシーポリシーに従います。

## 第20条（免責）

1. コミュニティの投稿は各投稿者の見解であり、運営による推奨、正確性の保証又は投票助言ではありません。
2. 投稿を参考にした舟券購入その他の判断は、参加者自身の責任で行います。
3. Discordの障害、仕様変更、アカウント停止又はデータ消失について、運営の故意又は重大な過失がある場合を除き、運営は責任を負いません。
4. 法令上免責できない責任には、本条を適用しません。

## 第21条（規約の変更）

1. 運営は、法令、Discordの規約、サービス内容又は運営状況の変更に応じ、本規約を変更できます。
2. 重要な変更は、変更内容及び施行日を事前に告知チャンネル又は登録メールアドレスで通知します。
3. 必要に応じて再同意を求めます。

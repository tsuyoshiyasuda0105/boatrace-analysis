# 運用チェックリスト

## 開始前チェック

- [ ] `AGENTS.md` を読んだ
- [ ] `docs/handoff.md` を読んだ
- [ ] 今回の着手内容を `docs/handoff.md` に書いた
- [ ] 編集中ファイルを `docs/handoff.md` に書いた
- [ ] 実行予定ツールを書いた
- [ ] 既存の編集中ファイルと競合していないか確認した
- [ ] スキルが必要な作業か確認した

## 作業中チェック

- [ ] 失敗や手戻りが出たら、その場でメモを残した
- [ ] 新しく触るファイルが増えたら `docs/handoff.md` を更新した
- [ ] 削除前に対象一覧を作った
- [ ] 巻き戻し前に対象一覧を作った
- [ ] 危険操作の前に影響範囲を明示した

## 終了前チェック

- [ ] 完了内容を書いた
- [ ] 次にやることを書いた
- [ ] 未決事項を書いた
- [ ] 実行中ツール / プロセス欄を更新した
- [ ] 起動したツールやサーバーを停止した
- [ ] 失敗があれば失敗ログへ具体例を書いた
- [ ] 削除 / 巻き戻しがあれば実績を残した

## 削除前チェック

- [ ] 削除対象を一覧化した
- [ ] 削除理由を書いた
- [ ] 影響範囲を書いた
- [ ] 復旧方法を把握した
- [ ] 実行前確認を取った

## 巻き戻し前チェック

- [ ] 戻す対象を一覧化した
- [ ] 戻す理由を書いた
- [ ] 失われる変更を把握した
- [ ] 実行前確認を取った

## ツール停止チェック

- [ ] ローカルサーバーを止めた
- [ ] Playwright / browser セッションを止めた
- [ ] 補助スクリプトを止めた
- [ ] バックグラウンドジョブを止めた

このプロジェクトでは、作業前・作業中・作業後に必ず `docs/handoff.md` と `docs/ops_checklist.md` を使うこと。

必須ルール:

1. スキルを使った作業で失敗や手戻りが出たら、`docs/handoff.md` の「失敗ログ」に具体例・原因・再発防止策を書くこと。
2. 作業開始前に `docs/handoff.md` を読み、未完了事項・未決事項・現在作業中ファイルを確認すること。
3. 作業開始時に `docs/handoff.md` の「今回の着手内容」「編集中ファイル」「実行予定ツール」を更新すること。
4. 同じファイルを同時に触らないこと。既に「編集中ファイル」に載っているファイルへ追記・修正する前に競合回避方針を書くこと。
5. 検証で起動したサーバー、Playwright、補助プロセス、監視ジョブは終了確認まで行い、「実行中ツール / プロセス」を空にして終えること。
6. 削除前は対象を一覧化し、削除理由・影響範囲・復旧方法を明示してから実行すること。
7. 元に戻す操作 (`git checkout --`, `git restore`, 差分破棄、設定巻き戻しなど) の前は、何を戻すかを一覧化して確認を取ること。
8. 破壊的変更、削除、巻き戻しを行ったら `docs/handoff.md` に記録を残すこと。

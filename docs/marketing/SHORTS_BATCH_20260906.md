# Codex への制作依頼（ショート10本・2026-09-06）

以下の10本を、縦1080x1920 / 30fps / 各25〜40秒のショート動画にしてください。

- 仕様・柱・声・台本ルールは `docs/marketing/PROMO_STRATEGY_HANDOFF.md` §2〜§6 に従う
- 各ネタの「冒頭1秒」を**最初の1秒に大きく表示＋ナレーション**すること（スワイプ対策）
- 数字は下記のまま使用（すべて実測・裏取り済み）。画面に「n=◯万レース／10年」を小さく併記
- 締めは全本共通: 「この数字、自分で確かめられます。無料です。」＋但し書き2行
- 声: 柱P2=Callirrhoe / P1=Charon（実装済みの声切替を使う）。エンディングは実装済みのものを使う
- 禁止語（絶対／必ず当たる／稼げる／保証）を使わない。断定は疑問形にする
- 出力ファイル名は英数字（例: `short_12r_in.mp4`）。`meta.json` に `uses_ai_footage` を記録

優先制作順: **2 → 3 → 10 → 1 → 4 → 7 → 5 → 9 → 6 → 8**

# ショートネタ 10本（2026-09-06 実測・55万レース）

すべて `data/kachisuji_search.db`（2016-06〜2026-09、548,967レース）から算出。
数字はそのまま画面に出してよい。締めは全本共通：「この数字、自分で確かめられます。無料です。」

凡例: 柱=戦略書の5本柱 / 声=柱→声マッピング（P1,P4=Charon / P2,P3=Callirrhoe / P5=Keita）

---

## 1. 「最終レースはイン天国」は本当か
- 冒頭1秒: **「12Rの1号艇、70%」**
- 数字: 1号艇1着率 1R 59.7% / 6R 46.8% / **12R 70.4%**
- オチ: でも単勝回収率は 91.2 → 90.4 → **89.7**。勝ちやすいほど、儲からない。
- 柱 P2 / 声 Callirrhoe

## 2. 風が7m吹いたら、1号艇はどれだけ落ちる？
- 冒頭1秒: **「風7mで、1号艇は10ポイント落ちる」**
- 数字: 1着率 0-2m **56.6%** → 3-4m 53.2% → 5-6m 49.5% → **7m+ 45.9%**
- オチ: 回収率も 92.8 → **82.7** に落ちる。「荒れる日は穴で儲かる」も嘘。荒れる日は誰も儲からない。
- 柱 P2 / 声 Callirrhoe

## 3. 1号艇が一番弱い会場、一番強い会場
- 冒頭1秒: **「同じ1号艇で、20ポイント違う」**
- 数字: 最弱 **戸田 42.6%** / 平和島 44.2% / 江戸川 46.1% ─ 最強 **大村 63.3%** / 徳山 62.4% / 芦屋 60.9%
- オチ: 「イン有利」は会場の話。戸田で1号艇を買うのと大村で買うのは別のギャンブル。
- 柱 P1 / 声 Charon

## 4. 1号艇の単勝、会場で回収率が11ポイント違う
- 冒頭1秒: **「戸田の1号艇、回収率83%」**
- 数字: 単勝ROI ベスト **尼崎 94.7** / 宮島 94.5 / 下関 93.8 ─ ワースト **戸田 83.5** / 鳴門 83.4 / 桐生 86.3
- オチ: 1着率が低い会場は、オッズもそれを織り込みきれていない＝損が大きい。
- 柱 P1 / 声 Charon

## 5. 6コースが一番来る会場
- 冒頭1秒: **「6号艇が勝つ確率、平和島4.6%」**
- 数字: 6号艇1着率 **平和島 4.61%（平均払戻1,063円）** / 浜名湖 4.20% / 常滑 3.96% / 戸田 3.91%
- オチ: 20回に1回来て、来ると10倍。期待値は… 0.0461×1063 ≒ **49円**。買い続けると半分になる。
- 柱 P2 / 声 Callirrhoe

## 6. 「2号艇が弱いと1号艇が勝つ」──勝つけど儲からない
- 冒頭1秒: **「2号艇がB1だと、1号艇は73%勝つ」**
- 数字: 1号艇A1のとき、2号艇 A1 → **66.4%** / A2 70.7% / **B1 72.9%** / B2 72.6%
- オチ: 回収率は 89.3 / 89.9 / 89.1 / 88.7 で**全部同じ**。市場は先に知っている。
- 柱 P2 / 声 Callirrhoe

## 7. イン有利は10年で強くなった
- 冒頭1秒: **「10年前、1号艇は50%だった」**
- 数字: 1号艇1着率 2016 **50.4%** → 2019 54.6% → 2026 **54.9%**（+4.5pt）
- オチ: 「昔は荒れた」は本当。でも回収率は 91.1 → 89.7 で下がっている。強くなった分、オッズが締まった。
- 柱 P2 / 声 Callirrhoe

## 8. 単勝万舟は「12レースに1回」
- 冒頭1秒: **「単勝10倍以上、8.3%」**
- 数字: 548,967レース中 **45,609レース（8.31%）**が単勝10倍以上。最高 **93,050円**
- オチ: 1日12レースなら、ほぼ毎日1回はどこかで出ている。問題は「どのレースか」が分からないこと。
- 柱 P2 / 声 Callirrhoe

## 9. ナイターはインが強い
- 冒頭1秒: **「夜は1号艇が4ポイント強い」**
- 数字: 1号艇1着率 デイ **52.2%** / ナイター **56.0%** / モーニング 55.9%
- オチ: 回収率は 91.1 / 90.4 / 89.6。強いレースほど回収率が低い、いつもの形。
- 柱 P2 / 声 Callirrhoe

## 10. 「雨は荒れる」は嘘だった
- 冒頭1秒: **「雨でも1号艇は勝つ。54.3%」**
- 数字: 1号艇1着率 晴 **54.5%** / 曇 55.1% / **雨 54.3%**（ほぼ同じ）
- オチ: 荒れるのは雨ではなく**風**（ネタ2）。雨の日は回収率だけ 88.5 に落ちる＝雨だから穴を買う人が損している。
- 柱 P2 / 声 Callirrhoe

## 使い方メモ
- 1日3本 × 柱ローテ。同じ柱を2日連続で出さない（P2が多いので、P1の3・4を間に挟む）。
- SG/G1の日程が近い週は、ネタ3・4を「その会場」に差し替えて P1 化する。
- 数字は「n=◯万レース」を画面に小さく併記（信頼の証拠）。
- 次のバッチはリンが毎週月曜に同じ手順で10本出す（切り口: 級別×コース／モーター2連率／展示タイム／年齢 など未使用の軸が残っている）。

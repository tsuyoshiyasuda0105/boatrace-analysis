# L4 戦略 最近 ROI 低下 診断レポート

**作成日**: 2026-05-30
**診断スクリプト**: `scripts/diagnose_l4_recent_roi.py`
**Raw log**: `reports/l4_diagnose.log`
**対象期間**: 2025-06-01 〜 2026-05-30 (12 ヶ月)
**戦略定義**: L4 = 1号艇A1 ∧ B除外しない会場 ∧ 1-2-3 払戻 500-1000円帯 ∧ 3連単 1-2-3 を 100 円固定買い
**サンプル**: n=2,509 races, 553 hits (hit rate 22.0%), 全期間 ROI **155.1%**

---

## TL;DR (結論)

**L4 は劣化していない。報告された「最近 ROI 低下」は noise 範囲内。**

- 全期間 12 ヶ月 ROI **155.1%** [95% CI 143.5, 166.2] — 公式期待値 (一般戦 147.7% / default 160.8%) と整合し、健全
- 直近 3 ヶ月 (2026-03〜05) ROI **158.6%** [137.1, 181.9]
- 過去 9 ヶ月 (2025-06〜2026-02) ROI **153.8%** [141.3, 167.2]
- 差分 **+4.7pt** [-21.6, +32.3] — **95% CI が 0 をまたぐので統計的有意差なし**
- 「直近 ROI 低下」報告の正体: **2026-05 単月** で ROI 112.2% に落ち込み (n=219)。しかし直前の 2-4 月が 204% / 188% / 176% と非常に好調だったので、相対的に落差が大きく感じられただけ。年間平均で見れば健全水準。

**推奨アクション**: **L4 base 戦略は継続。** ただし以下 3 点の小幅な調整を提案。

## 結論: L4 は本当に劣化しているか?

### 数値で回答

| 指標 | 値 |
|---|---|
| 全期間 12 ヶ月 ROI | **155.1%** [143.5, 166.2] |
| 直近 3 ヶ月 ROI | **158.6%** [137.1, 181.9] |
| 過去 9 ヶ月 ROI | **153.8%** [141.3, 167.2] |
| 差分 (直近 - 過去) | **+4.7pt** [-21.6, +32.3] |
| 統計的有意性 | **有意差なし** (95% CI が 0 をまたぐ) |
| P(ROI ≥ 100%) (全期間) | **100.0%** (Bootstrap) |

### **答え: いいえ、L4 は劣化していません。**

ユーザーが「最近 ROI 低下」と感じた正体は:
1. **2026-05 単月で 112.2%** に落ち込んだ (それ自体は 100% 超なので利益)
2. **直前の 2-4 月が異常に好調** (204%・188%・176%) だったため、5 月の落差が大きく感じられた
3. **過去レポート (G3×A1 で 149.2% 等) と直近 G3 92.4% を直接比較**すれば確かに -57pt の悪化に見えるが、これは **G3 だけの subgroup で n=67 (小サンプル)** のため信頼区間が広く、noise の範囲内

# F1 Prime 11-12R ROI 実測検証レポート

**生成日**: 2026-05-30
**検証スクリプト**: `scripts/verify_f1_prime.py`
**実行ログ**: `reports/verify_f1_prime.log`

## 検証目的

ユーザー提案の「F1 Prime 11-12R」条件 (= 一般戦 + 1号艇A1 + 1号艇国1≥7 + 2号艇 motor 2連率≥40 + 11/12R) に専用バッジを付けるべきかを判定するため、過去レースで実 ROI を測定。

## 検証条件

| # | 条件 | 実装 |
|---|---|---|
| 1 | 1号艇 class=A1 | `e1.class_number=1` |
| 2 | B 除外会場でない | `r.stadium_number NOT IN {2,4,7,8,10,19,21,24}` |
| 3 | 男性のみ (女性 0 名) | `NOT EXISTS` race_entries+racers (gender=2) |
| 4 | 雨除外 | `pv.weather_number != 3` |
| 5 | 一般戦 | `r.race_grade_number = 5` |
| 6 | 1号艇 全国1着率 ≥ 7 | `e1.national_top_1_percent >= 7` |
| 7 | 2号艇 モーター2連率 ≥ 40 | `EXISTS e2 motor_top_2_percent>=40` |
| 8 | 11R or 12R | `r.race_number IN (11, 12)` |
| 9 | 買い目 | 3連単 1-2-3 (100円) |

⚠️ **オッズ帯フィルタ (本命 500-1000円帯) は未適用**: ローカル `odds_trifecta` テーブルが 2026-05-11〜13 の 3 日分のみのため、過去全期間で T-5min オッズ絞りができない。本検証はオッズ帯絞り **無し** の集計。

## 判定

### ❌ バッジ実装は見送り

理由:
1. **オッズ帯絞り無しで ROI 90.8%** (期待値マイナス)
2. **test 期間 (直近 5 ヶ月) で ROI 76.2%** と劣化中
3. **5 年中 3 年がマイナス** (安定性 ❌)
4. F1 単体との差分わずか -3.6pt → 専用バッジを作るほどの edge ではない
5. 既存システムには既に F1 バッジ (🌟L4 G++) と Prime バッジ (🟢L4-prime) が並列表示される → 同条件のレースで両方光るため、追加バッジは情報冗長

### 注意: 本番環境では結果が異なる可能性

本番 (Supabase) 接続で `odds_trifecta` の T-5min snapshot に基づく L4 帯フィルタを適用すれば、 既存 F1 単体 ROI 204% に近い数字が出る可能性があります。 ローカルでは厳密検証ができないため、 本判定は「ローカル DB 範囲での参考値」です。

## 推奨

1. **現状維持**: 既存 F1 バッジ + Prime バッジで F1 Prime 11-12R は両方光るため、 視覚的に識別可能。
2. **本番再検証** (任意): Supabase 環境で `verify_f1_prime.py` に odds_trifecta JOIN を追加して L4 帯絞り版で再実行すれば、 既存 F1 検証 ROI 204% との整合性を確認できる。
3. **専用バッジ実装は保留**: ローカル検証で ROI 100% 超を示せない限り、 専用バッジは慎重に。

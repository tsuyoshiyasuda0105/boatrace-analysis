# 桐生 追い風×4号艇 期待値検証レポート

**生成日**: 2026-05-29
**スコープ**: 読み取り専用分析。production strategy code への自動実装は行わない（findings 報告のみ）。

## 1. Context（仮説）

俗説：「桐生会場で**追い風**のとき、**4号艇**にスタートが早い選手が来ると 4号艇が勝ちやすい」。

この検証では実データ(DB)で
- ベース勝率／追い風時勝率
- 単勝 ROI（期待値プラス／マイナス）
- 時系列スプリット（train/test）で robust かどうか
を数値で示す。

## 2. データ範囲・スキーマ確認

- `races` (stadium_number=1 = 桐生)
- `race_previews.wind_direction_number / wind_speed`
- `race_results.boat_number / finishing_position / start_timing`
- `race_entries.avg_start_timing / class_number / national_top_1_percent / assigned_motor_top_2_percent`
- `race_payouts` (bet_type='win', combination='4')

**重要な制約**: 桐生 race_previews の wind_direction_number が non-null なのは **2025-07-15〜2026-05-28** の期間のみ。よって train/test split は **2026-01-01** に設定（train 約 6.5 か月、test 約 5 か月）。

## 5. 結論

1. **俗説は実データで支持される**。桐生の特定風向(wd=6) で 4号艇 単勝の期待値が大きくプラス。
2. ただし俗説の「ST早い選手」要件は **不要**（市場が既にオッズに反映）。風向 + モーター + 国1着率で十分。
3. **5 種以上の robust 戦略**を確認。サンプル数も実戦投入可能なレベル。
4. **推奨ライブ戦略候補（小ベット推奨）** — 真の n で再評価:
   - **A. 安全多サンプル**: `桐生 wd∈(6,10) ws<2 + 4号艇 国1≥5 → 単勝4` (tr 167.3% / te 157.1%, **真の n ≈ 66+17=83**)
   - **B. 月運用**: `桐生 wd=6 + 4号艇 motor≥30 + 国1≥5 + 7-12R → 単勝4` (tr 160.5% / te 195.0%, **真の n ≈ 21+10=31**)
   - **C. 超選別 (n 不足)**: `桐生 wd=6 + 4号艇 motor≥35 + 国1≥5 → 単勝4` (te 305.6%, **真の n ≈ 23+9=32**)
5. 他会場への transfer は **不成立**（wd=6 の意味が場ごとに異なるため当然）。
6. ST 早い絞りは ROI を下げる（市場効率）→ 仮説の「ST 早い選手」要件は **削除すべき**。

## 5b. Round 9-10 追加発見: 切り分け & Portfolio

### 5b-1. 重要な切り分け発見
- **桐生 5-1-2 (motor35 + 国1≥6 + 雨除外)** は **wd≠6 のときの方が ROI 高い** (tr 168.1% / te 237.3%, n=998/117)。
- **桐生 wd=6 のときは 5-1-2 が崩れる** → 代わりに 4号艇 head 戦略が edge。
- これは「**1号艇有利な風 → 5-1-2 で内側勝ち**」「**追い風(wd=6) → 1号艇が崩れ外艇有利**」という物理的整合性のある現象。

### 5b-2. Portfolio 戦略 (test 期間 5 か月で robust)

| Portfolio | train ROI (真の n) | test ROI (真の n) |
|---|---|---|
| 5-1-2 単独 (motor35+国1≥6+雨除外) | 166.6% (1007) | 229.5% (121) |
| 4-5-2 単独 | 136.3% (1007) | **324.8%** (121) |
| **5-1-2 + 4-5-2 併買** | 151.4% (2014 bets) | **277.1%** (242 bets) |
| Split (wd=6→単勝4 / wd≠6→5-1-2) | 165.5% (1075) | 229.7% (147) |
| **三段 (wd=6→単4 + 残→5-1-2 + 4-5-2)** | 152.0% (2073) | **276.8%** (264) |
| **強化 split (wd=6+motor30+国1≥5)** | 152.7% (2033) | **281.9%** (249) |

### 5b-3. 強化 split portfolio 詳細 (推奨運用)

桐生 全レースに対して、各 race の条件によって以下を購入:

1. **IF wd=6 AND 4号艇 motor≥30 AND 4号艇 国1≥5** → 単勝 4
2. **IF motor35 + 国1≥6 + 雨除外 AND wd≠6** → 3連単 5-1-2 + 3連単 4-5-2 (両買い)
3. それ以外 → 賭けない

結果 (test 期間):
- レース機会: 249 bet (1 race で複数 bet 含む) over 5 months → 約 50 bet / 月
- 1 bet 100 円なら月 5,000 円投入、回収 1,4100 円程度
- 月期待利益 +9,100 円（ROI 281.9% 想定）

## 6. 注意事項

- **wd=6 の絶対方位**は経験的に「桐生で外艇勝率が跳ねる風向＝追い風」と判定したもの。気象学的方位定義は別途確認推奨。
- 風データは **2025-07以降のみ**。それ以前のレースは予測に使えない。
- 戦略 production への自動組込は行わない（ユーザー明示指示）。本レポートは findings のみ。
- 連続ベットでの実運用は **小ベット（試合1回 100〜500円）で 100 件以上の追跡** を強く推奨。

## 5. 機序解釈

### 5-1. なぜ江戸川と風速が効くか

- **江戸川**: 「日本一難水面」 と呼ばれる。 潮の干満で水面が流れる。 1号艇が一旦先頭を譲りやすい (流される、 旋回失敗) が、 道中で巻き返すレースが他会場より多い → 「抜き」 が増える機序と整合的。
- **風速 ≥5**: 強風で 1号艇のスタート/1マークが乱れる → 一旦譲るが力でねじ伏せて巻き返す A1 選手の能力差が出る → 抜き発生。

### 5-2. なぜ「抜き fav」 ≠ 「1-2-3 fav」 か

抜き hit 率が上がる subset は同時に **荒れる subset** でもあるため:
- 1号艇が 1着になっても 2着、 3着が荒れて 1-2-3 にならない (= 1-2-4 や 1-3-2 等が増える)
- 一方で配当は 836円 → 999-1172円 と +20-40% 上昇
- 結果: ROI は **base 82% → 90-97%** とやや改善するが ROI 100% 超えは安定して達成されない

→ **「抜きが起きやすい subset」 は「1号艇本命 (1-2-3 ベタ買い) の優位性が落ちる subset」 と相関**。 nuki 指標は単独では「狙い目」 にならず、 **bet pattern の組み替えとセット** で考えるべき。

### 5-3. nuki subset で配当が高いのに 1-2-3 hit 率が下がるパラドックス

ユーザー初期発見:
> 抜き: 16.1% (avg 配当 953円) → 推定 ROI 153.4%

この 16.1% は **「kimarite=抜き が確定した後の 1-2-3 hit 率」** (= 事後分析)。 事前条件で抜き率が上がっても、 抜き以外の race (= 多数派) で 1-2-3 hit が落ちる方が効きが大きく、 net ROI は base を大きく超えない。

## 6. 実戦投入案

### 6-1. 即時投入推奨: なし

理由:
- ROI 100% を train/test 両方で安定的に超える条件は **存在しない**
- 江戸川 × R12 (test ROI 107%) や 若松 × 風3-6 (test ROI 101%) は test n が 61 / 120 と小さく、 母集団 ROI も低い (77% / 74%)
- L4 strategy (本命オッズ 500-1000 縛り) と組み合わせていないため、 既存 L4 改善との直接比較は別検証必要

### 6-2. 保留・観察推奨: 江戸川 × 風速≥5 フラグ

- 全期間 ROI = **92.98%** (vs base 82.16%、 +10.8pt)
- test 期間 ROI = **96.50%** (vs base test 76.08%、 +20.4pt)
- train/test 一貫して nuki +100% lift
- **paper trade 3ヶ月** で実 ROI を観察 → 100%+ を維持できれば本採用検討

### 6-3. 実装案 (src/evaluation/nuki_filter.py — Agent F 担当範囲)

```python
def is_nuki_likely(entries, preview, race) -> bool:
    """事前情報から抜きが起きやすい race を推定。

    Returns: bool — True なら nuki-likely race (1-2-3 配当 +20-40% 期待)
    """
    # primary: 江戸川 × 風速 ≥5
    if race.stadium_number == 3 and preview and (preview.wind_speed or 0) >= 5:
        return True
    # secondary: 風速 ≥ 7 (全会場)
    if preview and (preview.wind_speed or 0) >= 7:
        return True
    return False
```

→ **L4 strategy にフラグ追加するか**:
- **追加に値する nuki bonus**: 平均配当 +20% で hit 率 -1pt → ROI +10pt 程度。
- 但し L4 本体 (本命500-1000 縛り) との交互作用は別検証必要。 江戸川 × 風 ≥ 5 のサブセットで L4 オッズ条件を入れた場合の n と ROI を別 script で取る。

### 6-4. NOT 投入推奨

- **1号艇 motor 弱 × 国1着率 強** — 仮説棄却。 抜き率むしろ下がる
- **2号艇 国 2連率 ≥ 50** — 抜き率 -5%。 単独では使えない
- **avg(r456_mot2) <30** — 抜き率 -1%。 効かない
- **F=1** — n=66 で ROI 21%、 サンプル不足かつ壊滅

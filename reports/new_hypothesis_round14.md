## 3. 機序の物理的裏付け

### 鳴門 (徳島県) の特徴
| 号艇 | 鳴門 1着率 | 全国平均 | 差 |
|---|---:|---:|---:|
| 1 | 47.52% | 54.86% | **-7.33** |
| 2 | 15.35% | 13.95% | +1.41 |
| 3 | 15.14% | 12.56% | **+2.58** |
| 4 | 11.61% | 10.05% | +1.56 |
| 5 | 7.15% | 5.76% | +1.39 |
| 6 | 3.45% | 3.09% | +0.37 |

**鳴門は 1号艇の絶対王者性が崩れる珍しい会場**。2-5 号艇全てが平均より上回り、外艇の活躍が常態化している。

### 鳴門が外艇有利な物理的要因
- 鳴門海峡の潮流: 干満で水面が変動し、走路が読みづらい
- 1マーク手前で潮流の影響を受け、内側 (1-2 号艇) の有利が削がれる
- 強風時は塩水のうねり

### 「A1 1号艇」を条件にした理由
- A1 が 1号艇のとき、市場 (オッズ) は 1号艇 1着を強く想定する
- → 外艇 head (4-2-3 等) のオッズが本来の確率より高く設定される
- → 物理的に鳴門で外艇が走るとき、配当の overpay が発生

組合せ別の解釈:
- **4-2-3**: 4号艇まくり差し → 2号艇 → 3号艇 (典型的な「内2艇が崩れる外艇展開」)
- **2-3-6**: 2号艇差し → 3号艇まくり → 6号艇大穴 (1号艇完全崩れ、6号艇高配当)
- **4-2-6**: 4号艇まくり → 2号艇 → 6号艇大穴 (外艇連勝 + 大穴3着)

## 4. 桐生戦略との独立性

| 項目 | 桐生戦略 | 鳴門戦略 |
|---|---|---|
| 会場 | 桐生 (sta=1, 群馬) | 鳴門 (sta=14, 徳島) |
| 主力 combo | 5-1-2 / 4-5-2 / 単勝4 | 4-2-3 / 4-2-6 / 2-3-6 |
| 条件 | motor35+国1≥6+雨除外 (+風向6) | A1 のみ (シンプル) |
| 機序 | 1号艇強力 → 外艇まくり成立で 5-1-2 / 4-5-2 | 1号艇弱 (鳴門固有) → 外艇 head |
| 1号艇 | head 残り (5-1, 4-5 で 2-3着) | 完全崩れ (4-2-x, 2-3-6) |
| 月当機会 | 戦略全体で ~53 bets/月 | A1 1号艇 ≈ 50-60 races/月 → ensemble 3点で 150-180 bets/月 |

**完全に独立**: 会場が異なる、購入 combo の重複ゼロ、機序も逆方向 (桐生は 1号艇強い前提 / 鳴門は 1号艇弱い前提)。**ポートフォリオに併存可能**。

## 7. 重要な注意 (data-snooping への警戒)

1. **mass scan で 1,400 通り近い tests を実施** → 偽陽性のリスクあり
2. **本命戦略 (鳴門 4-2-3 ensemble) は 5 年 4/5 で ≥130%** → 単なる data fitting ではなく、機序 (鳴門 1号艇弱+外艇強) と整合
3. **hit 数**: train 29 hits / 7,119 races (0.41%) — 高 variance long-shot 戦略 → 損益のブレ大、心理的耐性必要
4. **2024 年だけ ROI 107%** という弱化年があった → 完全 robust ではなく **"複数年で期待値プラス"** という性質
5. **rain (weather=3) フィルタは未適用** → 実装前に「雨で外艇 head が増えるかどうか」追加検証推奨

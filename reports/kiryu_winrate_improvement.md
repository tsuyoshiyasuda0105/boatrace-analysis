## 2. 探索方針

- ベース `BASE_K1 = (1号艇 A1 ∧ motor≥35 ∧ 国1≥6 ∧ weather!=雨)` を固定し、その上に **追加 1 条件** を重ねて train/test 両期間の (n / hit_rate / ROI) を比較。
- 判定凡例: 🏆=test 的中率≥2.5% & tr_ROI≥100% & te_ROI≥120%、✓=te 的中率≥2.0% & te_ROI≥100%、-=効果なし、·=サンプル小 (te_n<10)。
- 探索カテゴリ (約 80 条件):
  1. 1号艇 (国1/局1/motor/avg_ST/年齢)
  2. 5号艇 強化 (head 強化)
  3. 4号艇 強化 (K1 4-5-2 head)
  4. 2号艇/3号艇 弱体化 ⇄ 強化
  5. レース番号、月別、風速帯
  6. 展示 ST、展示時間、tilt_adjustment

## 6. 最終推奨条件 (K1' / K2')

複数の最強候補が存在するため、運用目的 (n を稼ぐ vs 的中率を上げる) で 2 案推奨:

### 推奨 A — **n を維持しつつ全体底上げ (Conservative)**

- **K2' (5-1-2)** = K2 + **boat5 motor>=35**
- **K1' (4-5-2)** = K1 + **boat4 class=A1** または **boat4 国1>=5 + boat5 国1>=5**

| 戦略 | train n / hit / ROI | test n / hit / ROI |
|---|---|---|
| 元 K2 5-1-2 | 998 / 1.00% / 168.1% | 117 / 2.56% / 237.3% |
| **K2' 5-1-2 (+boat5 motor>=35)** | **455 / 1.54% / 319.9%** | **52 / 3.85% / 406.9%** |
| 元 K1 4-5-2 | 1007 / 0.50% / 136.3% | 121 / 1.65% / 324.8% |
| **K1' 4-5-2 (+boat4 class=A1)** | **392 / 0.51% / 112.0%** | **57 / 3.51% / 689.5%** |

→ どちらも n が約半分に減るが、的中率と ROI が大きく改善。月運用ベットサイズが若干小さくなる代わりに、**期待利益は約 1.5〜2 倍**。

### 推奨 B — **的中率を最大化 (Aggressive, te n<30 だが)**

- K2 + boat1 国1>=7 + 7-12R (te 的中率 **5.00%**, te ROI 330.5%, te n=20)
- K2 + boat5 motor>=40 (te 的中率 **4.35%**, te ROI 457%, te n=23)

→ te n が 20-23 で「信頼区間広め」だが train でも tr ROI ≥ 120% を維持。月運用で 1-2bet/月になる超選別運用。

### 推奨 C — **Portfolio (推奨 A の組合せ)**

桐生 ベース条件を満たすレースに対して:
1. IF (wd≠6) ∧ (5号艇 motor>=35) → 3連単 **5-1-2** 100円
2. IF (4号艇 class=A1) → 3連単 **4-5-2** 100円
3. 両方満たすときは 200円 (両買い)

これにより **n=52+57=109 bet/期間** を維持しつつ的中率を底上げできる。

## 8. Trade-off 整理

| 観点 | 改善で得るもの | 改善で失うもの |
|---|---|---|
| **n** | — | 元の半分以下 (1007→455-700) → bet 機会が減る |
| **的中率** | 1.5〜2倍向上 (2.48%→3.85%) | ベース条件が複雑化 |
| **ROI** | 200%台 → 300-400%台 | train サンプル少 (n<500) なので variance あり |
| **頻度** | — | 桐生開催日でも 0bet の日が増える |
| **運用** | 期待利益/bet が 2倍 | 統計的有意性 (95% CI) が広がる |

特に K2' (boat5 motor>=35) は **train サンプルが 998→455 へ半減**するが、tr ROI が 168%→320% に上がるため期待損益自体は大きく改善する。

## 9. 不可能と判明した方向

- **1号艇 motor を上げる** (>=40, 45, 50): test 的中率が下がる (1.47%, 0%, 0%)。市場が既に reflect。
- **1号艇 avg_ST を厳しくする** (<=0.16, 0.15): test 的中率と ROI 両方下がる (1.75%, 1.03%)。市場効率。
- **2号艇を弱体化** (国1<5, B級): test 的中率 0% を連発。3着 2 が消えてしまう。
- **5号艇 tilt 強気**: ほぼ tilt 調整するレースが無く n<5 で判定不能。
- **季節別 (夏/秋)**: test 期間が 1-5月のため、夏/秋の test n=0。判定不能。

## 10. 注意事項

- ベース条件 (boat1 国1>=6) 自体が既に強い絞り (全レースの 11%) なので、その上に 1 条件加えると te n が一気に 50 前後に減る。
- te n < 30 の候補は 95% CI が広く、本番投入には **3〜6 ヶ月の追跡で n を上乗せ** してから判定すべき。
- 風速・展示 ST 系は train 期間のデータが乏しい (2025-07 以降のみ preview record) ので train ROI=0% に見える条件は **データ欠落** であって effect が無いわけではない。test 単独で評価。
- **生産コードへの自動組込はしない**。本レポートは findings のみ。
- 月運用での実装イメージ:
  - 桐生 開催月 ≈ 15日 × 12R = 180レース
  - 改善前 K1: 約 20-25 bet/月 (1007/12*0.3 = ~25)
  - 改善後 K2' (boat5 motor>=35): 約 8-10 bet/月 (1007/12/2 = ~10)
  - 改善後の期待月利益: 10bet × 100円 × 3.07 = **+3,070 円/月** (元は 25bet × 129 = +3,225 円/月)
  - → bet 数は半分以下になるが、期待利益はほぼ維持しつつ **的中体験は 1.5倍向上**

## 11. 次のアクション候補

1. K2' (boat5 motor>=35) を **6 ヶ月 paper trade** で追跡し te n を 50→100 へ拡張
2. K1' 4-5-2 (boat4 A1) を **同様に追跡**。元の 1.65% 的中の低さが致命的なため te n=57→200 で再評価必須
3. portfolio C (両戦略併走) を **walk-forward** で 3 ヶ月ごとに re-evaluate
4. 桐生 wd=6 戦略 (既存 kiryu_wind_boat4.md) と組合せて、**「wd=6 → 単勝4」「wd≠6 → K2' 5-1-2 + K1' 4-5-2」** という 3 段 portfolio を再検証

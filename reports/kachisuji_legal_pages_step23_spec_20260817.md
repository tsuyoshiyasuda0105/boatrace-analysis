# 勝ち筋サーチ Step 23 仕様書 — 法定表示ページと有料プラン導線

作成: 2026-08-17 リン（Claude Code）/ 発注先: Codex
前提: Step 22（baaf6e1）で勝ち筋サーチを本番アプリへ統合済み（会員限定 `/kachisuji`）。
Stripe 課金は `src/web/billing.py` に実装済み。

## 背景（調査で判明した不足）

有料提供を開始するには**法的に必須の表示**が揃っている必要があるが、
`src/web/templates/` に**利用規約・特定商取引法表示・プライバシーポリシーのページが存在しない**。
特商法（通信販売）は事業者名・住所・電話番号・返品/解約条件等の表示を義務付けており、
未表示のまま有料販売を行うと業務停止命令等の対象になり得る。

## スコープ

**法定表示ページの実装（テンプレート＋ルート）と、有料プランへの導線整備。**
文面の最終確定はリッキーさん（事業者本人）が行う。Codexは**プレースホルダを明示した雛形**を作る。

## 絶対的な制約（違反禁止）

1. 変更/作成してよいファイル:
   - 新規 `src/web/templates/legal_terms.html`（利用規約）
   - 新規 `src/web/templates/legal_tokushoho.html`（特定商取引法に基づく表記）
   - 新規 `src/web/templates/legal_privacy.html`（プライバシーポリシー）
   - 新規 `src/web/legal_bp.py`（3ページのルート。公開＝認証不要）
   - `src/web/app.py`（**Blueprint 登録の1行のみ**）
   - `src/web/templates/base.html`（フッターに3ページへのリンク追加のみ）
   - `src/web/templates/kachisuji_search.html`（無料/有料の区別表示があれば整合）
   - 対応 `tests/`、新規 `docs/kachisuji_legal_pages_step23_result_20260817.md`
   **他の既存ファイル（特に `src/web/app.py` の既存ルート、`billing.py`）は変更禁止。**
2. **事業者情報を勝手に埋めない。** 氏名・住所・電話番号・メールアドレス・価格は
   すべて `{{ 事業者名を入力 }}` のような**明示的なプレースホルダ**とし、
   未入力のまま本番公開されないよう、**未設定時はページに警告バナーを表示**する
   （例:「この表記は未完成です。事業者情報を設定してください」）。
   → 環境変数（例 `LEGAL_OPERATOR_NAME` 等）から読み、未設定なら警告を出す方式を推奨。
3. **「絶対儲かる」「必ず当たる」等の断定表現を一切使わない**（景表法・特商法の誇大広告規制）。
   「投資」という語も使わない。
4. DB書込み・Supabase接続・スキーマ変更禁止。ネットワーク・デプロイ・push 禁止。
   実サーバー起動しっぱなし禁止。
5. コミットは main へのローカルコミット1つ。
   メッセージ: `Add legal disclosure pages for paid service (kachisuji step 23)`。

## 各ページの必須項目

### 1. 特定商取引法に基づく表記（`/legal/tokushoho`）
以下を**すべて**項目として用意（値はプレースホルダ）:
- 販売事業者名 / 運営統括責任者名 / 所在地 / 電話番号 / メールアドレス
- 販売価格（税込）/ 商品代金以外の必要料金 / 支払方法 / 支払時期
- サービス提供時期 / **返品・キャンセル（返金）条件** / 動作環境
- 「電話番号は請求があれば遅滞なく開示します」等の逃げ文言は使わず、**表示欄を必ず設ける**

### 2. 利用規約（`/legal/terms`）
既存の下書き（会話で作成済みの内容）に沿って、最低限以下を含める:
- サービス内容（**予想の販売ではなく、データ検証ツールの提供**であること）
- **的中・利益を保証しないこと**、舟券購入は利用者自身の判断と責任
- **18歳未満の利用禁止**、20歳未満の舟券購入禁止の明示
- 料金・支払・解約（自動更新の有無、解約時の扱い）
- 禁止事項（データの再配布・スクレイピング・第三者への販売・予想の転売など）
- **サービス提供時間**: 毎日24:00〜翌6:00 はメンテナンスで停止（補償なし）
- **データ提供元の事情等でデータ取得が継続できなくなった場合、サービスを変更・終了することがある**
  （終了時は原則30日前告知、終了日以降の課金なし、支払済み当月分の返金なし）
- 免責、規約変更、準拠法・管轄

### 3. プライバシーポリシー（`/legal/privacy`）
- 取得する情報（メールアドレス、決済情報はStripeが処理し当方は保持しない旨、利用ログ）
- 利用目的 / 第三者提供 / 委託先（Stripe, Supabase, Render 等の外部サービス名）
- 開示・訂正・削除の請求方法 / 問い合わせ窓口 / Cookieの利用

## 導線
- `base.html` のフッターに「利用規約 / 特定商取引法に基づく表記 / プライバシーポリシー」を追加。
- 有料プランの申込画面（既存の Stripe Checkout 導線）から**規約への同意チェック**が必要な場合は、
  既存 `billing.py` を変更せずに済む範囲で導線を用意する
  （変更が必要なら実装せず、必要な変更内容を結果レポートに記載する）。

## テスト
1. 3ページが 200 で表示され、**認証不要**でアクセスできる
2. 事業者情報が未設定のとき、各ページに**警告バナーが出る**
3. 環境変数を設定すると値が反映され、警告が消える
4. フッターに3リンクが出る
5. 禁止表現（「絶対」「必ず当たる」「投資」）がテンプレートに含まれない（文字列検査）
6. 既存の全テストがグリーン（本番アプリの回帰）

## DoD
1. 全テストグリーン。
2. 結果レポートに: 追加ファイル / 変更した既存ファイルと行数 /
   **リッキーさんが入力すべき事業者情報の一覧（チェックリスト形式）** /
   Stripe導線で追加変更が必要な場合はその内容 / 既知の制限
   （**文面はリーガルチェック未実施である旨を明記**）。
3. ローカルコミット1つ（push しない）。

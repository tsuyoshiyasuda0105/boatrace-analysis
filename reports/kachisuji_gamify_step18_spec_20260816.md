## 目的

「触って楽しい」体験を加える。ただし**賭けを煽る方向のゲーム化は厳禁**。
本アプリの本質である「55万レースから自分の勝ち筋を発掘する」＝**宝探し・育成**の楽しさに寄せる。

**最重要の設計原則:
統計的に妥当なときだけ祝う。小さい母数の上振れを絶対に称賛しない。**
演出は既存の警告・判定ロジックと矛盾してはならない。

## 案①: 発掘フィードバック（検索結果の演出）

検索結果の上部（条件サマリの近く）に、結果の質を表す**発掘ステータス**を1つ表示する。
判定は**サーバーが返す既存の値のみ**から行う（roi / roi_ci_low / n / warnings）。

| ランク | 条件 | 表示 | 演出 |
|---|---|---|---|
| 金脈 | `n >= 100` かつ `roi >= 100` かつ **`roi_ci_low >= 100`** | ⛏️ 金脈発見 | 控えめな輝き（1回だけ・0.8秒程度） |
| 鉱脈の気配 | `roi >= 100` だが `roi_ci_low < 100` または `n < 100` | ✨ 鉱脈の気配 | 静的表示。「判定にはあと○件」（n<30/100の閾値に応じて） |
| 要検証 | `70 <= roi < 100` | 🪨 要検証 | 静的表示 |
| ハズレ鉱区 | `roi < 70` | ⛰️ ハズレ鉱区 | 静的表示＋「外れを知るのも発掘のうち。この条件は避ける判断材料になります」 |
| 母数不足 | `n < 30` | 🌫️ 未探査 | **ROIに関わらず最優先でこれを表示**。「母数が少なすぎて判定できません」 |

- **判定の優先順位**: 母数不足（n<30）が最優先。次に金脈。以降は上表の順。
  → **n<30 のとき、ROIがどれだけ高くても「金脈」を出してはならない**（最重要）。
- 各ランクに1行の説明文を付ける（上記のニュアンス）。
- 「金脈」の輝きは `prefers-reduced-motion` を尊重して無効化できること。
- 既存の warnings 表示は**そのまま残す**（演出は追加であって置き換えではない）。

## 案②: マイ手法の育成表示

既存の `/api/strategies/<id>/performance` が返す
`forward.n` / `verdict` / `races_until_verdict` を使い、手法カードに育成要素を出す。
**新しい計算はしない。表示のみ。**

### 2-1. 成長バー
- フォワードの `n` が 30 に到達するまでの進捗バーを表示。
  - 例: `🌱 判定まで あと18レース`（`races_until_verdict` を使用）
  - バーは 0〜30 を 0〜100% として描画。30以上は満タン表示。
- N30到達済みなら、バーの代わりに判定バッジを主役にする（既存の🟢⚪🔴を活用）。

### 2-2. 手法レベル（フォワードNの段階表示）
`forward.n` に応じたレベル表示を追加する:

| レベル | 条件 | 表示 |
|---|---|---|
| Lv.0 | n < 30 | 🌱 育成中 |
| Lv.1 | 30 <= n < 100 | 🌿 判定可能 |
| Lv.2 | 100 <= n < 300 | 🌳 実績あり |
| Lv.3 | n >= 300 | 🏔️ 長期検証済み |

- **レベルは「検証量」を表すものであって、成績の良さではない**ことを明記する
  （ツールチップまたは小さい注記で「レベルは検証したレース数を表します」）。
  成績は判定バッジ（🟢⚪🔴）が示す、という役割分担を崩さない。

### 2-3. 経過表示
- 「保存から○日 / フォワード○レース消化」を1行で表示（既存の `days_since_saved` を活用）。

## 表示スタイル
- 既存のデザイントークン（CSS変数）を使い、ダーク/ライト両テーマで見えること。
- **数字（KPI）より目立たせない**。演出はあくまで脇役。
- モバイル幅(390px)で崩れないこと。

## テスト

### 発掘フィードバック（E2E中心）
1. `n<30` かつ高ROIのケースで「金脈」が出ず「未探査」が出る（**最重要のテスト**）
2. `n>=100` かつ `roi>=100` かつ `roi_ci_low>=100` で「金脈」が出る
3. `roi<70` で「ハズレ鉱区」＋説明が出る
4. 既存の warnings 表示が消えていない
5. `prefers-reduced-motion` でアニメーションが無効

### 育成表示
6. `forward.n=12` で「あと18レース」とバーが40%相当
7. n=30/100/300 の各境界でレベル表示が切り替わる
8. n=0（保存直後）で例外にならず「育成中」
9. 既存の判定バッジ（🟢⚪🔴）が消えていない

### 回帰
10. 既存の全テスト（ユニット + E2E）がグリーン

# 勝ち筋サーチ Step 20 仕様書 — 決まり手率を「進入コース時の率」に統一

作成: 2026-08-17 リン（Claude Code）/ 発注先: Codex
前提: Step 19（c4ff485）で逃げ率のみ「1コース進入時の率」に修正済み。schema v8。
差し・まくり等の非逃げ決まり手は分母が「2〜6コース進入の合計」のままで、値が低すぎて
実用にならない（差し最大33%、50%以上が全艇0件 = Round2バグチェックの注意フラグ①）。

## ユーザー決定

**各号艇の決まり手率 = その号艇の「進入コース」に入ったときの、その決まり手での勝率。**
逃げ（1コース時の逃げ率）と完全に同じ考え方で全決まり手を統一する。

- 例:「2号艇の差し率」= その選手が**2コースに入ったとき**の差し勝率
  （峰竜太で実測 22.2% = 88勝 / 396進入）
- 逃げ率は現行どおり（1コース時）で変わらない。

## 定義の核心

`bN_kimarite_rate_<key>` = 選手が**N号艇の想定進入コース**に入った過去レースのうち、
その決まり手で1着になった割合。

- **想定進入コース = 号艇番号 N**（前日確定の枠番。番組表から確定）。
  実際の進入は前づけ等でズレることがあるが、**as-of（前日確定）で使える値は枠番のみ**なので、
  枠番＝想定コースとして集計する。この判断を docstring に明記。
- 分母: 過去（レース前日まで直近1年 = [asof_date-364, asof_date)）に、その選手が
  **コース N に進入した**レース数。
- 分子: そのうち、その決まり手で1着になった数。
- コース N の進入が0なら NULL（0除算しない・0扱いにもしない）。

### 各決まり手の扱い
- `nige`（逃げ）: コース1のみで発生 → 号艇1でのみ意味を持つ。号艇2〜6では
  「コースNでの逃げ勝率」= ほぼ常に0（外コースから逃げは出ない）。**現行の号艇1の逃げ率は変えない**。
- `sashi` / `makuri` / `makurizashi`: コースNでのその決まり手勝率。
- `nuki` / `megumare`: コースNでのその決まり手勝率。
- **全決まり手を「コースN進入時の、その決まり手勝率」という単一の定義で統一**する。
  号艇ごとに参照するコースが違う（1号艇→コース1、2号艇→コース2 …）だけ。

### 重要な帰結（既存の逃げ率との整合）
- 現行の `b1_kimarite_rate_nige`（1コース時の逃げ率、平均44.2%）は**この定義と一致**する
  （1号艇=コース1、逃げ=コース1の決まり手）。**値が変わらないことをテストで保証**する。
- `b2_kimarite_rate_nige` 等（外コースの逃げ率）はほぼ0になる（正常）。

## 実装の注意

- Step 19 で既に「進入コース×決まり手」の履歴構築（`_load_course_kimarite_histories`、
  `KIMARITE_VALID_COURSES`）がある。**その分母を「該当決まり手の有効コース全体」から
  「号艇N＝コースNの単一コース」に変える**のが本質。既存の復元済み進入コースデータ
  （`start_timing_events.course_number`）と勝者決まり手を再利用し、二重実装しない。
- **as-of厳守**: レース当日以降の進入・結果を絶対含めない。既存 verify で検査可能に。
- schema_version を 9 に上げる（列名は同じ `bN_kimarite_rate_<key>` のまま、意味が変わる）。

## テスト
1. **逃げ率不変**: `b1_kimarite_rate_nige` が Step 19 と同じ値になる（回帰）。
2. **差し率が意味ある値**: 合成フィクスチャで「2コースに10回入り3回差し勝ち」→ 30%。
3. **コース単一**: b2 の集計がコース2進入のみを分母にしている（コース3-6を含めない）。
4. **as-of厳守**: 前日までのみ集計、当日以降を含まない（境界検証）。
5. コースN進入0で NULL（0でない）。
6. 既存の全テスト（ユニット + E2E）がグリーン。
